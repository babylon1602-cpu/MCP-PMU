# Publication Checklist

1. Create a new public GitHub repository.
2. Unzip the archive locally.
3. Rename `your-username` and `your-repo` in the CI badge URL.
4. Review `README.md` and `README_PUBLIC.md`.
5. Verify `main.py` is the desired entry point.
6. Install dependencies: `pip install -r requirements.txt`.
7. Run `./run_checks.sh`.
8. Commit all files except caches and pyc files.
9. Push to GitHub.
10. Check that the CI workflow runs successfully.
