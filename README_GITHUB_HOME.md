# PMU Turf Read-Only MCP Server

Serveur MCP Python **lecture seule** pour consulter des données turf PMU.

## Quick start
```bash
pip install -r requirements.txt
python main.py
```

## Checks
```bash
./run_checks.sh
```

## Included
- MCP server
- tests
- smoke test
- GitHub Actions CI
- public entry point `main.py`
